# Датасет лекцій для глобального тесту ExplAI-2026

- `pdf/` — оригінали лекцій; `txt/` — текст, витягнутий `lecture_graph.read_lecture` (його отримує Аналітик).
- `manifest.csv|json` — id, split, дисципліна, назва, файл-джерело, символи, слова, сторінки, частка кирилиці, SHA-256 (16 знаків), `used_in_pilots`.
- Дизайн: 3 дисципліни × 3 лекції × 12 питань = 108 питань на конфігурацію (M1–M4).
  - W01–W03 — веб-розробка (PHP, Laravel); D01–D03 — бази даних і сховища даних; A01–A03 — інтелектуальна обробка інформації.
- `calibration` — Тема 7 (використана в пілотах і налаштуванні): не входить у статистику, придатна для калібрування арбітра.
- `reserve` — запасні лекції на випадок поганого розпізнавання.
- Застереження: A01 («Лекція 1…») використовувалась у пілотах 2–3 при налаштуванні системи; її результати слід позначити як не повністю незалежні.
- Усі лекції ≤ 50 000 символів. Тексти авторські, не нормалізуються.
- Папка `_to_delete/` — застарілі файли попередньої версії датасету (видаліть вручну).
