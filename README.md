# Мультиагентна генерація та верифікація тестових завдань

Програмна реалізація кваліфікаційної роботи магістра «Метод генерації та верифікації тестових завдань з використанням мультиагентних систем» (Хмельницький національний університет, кафедра комп’ютерних наук, 2026).

Система за текстом лекції створює тестові завдання множинного вибору (одна правильна відповідь і три дистрактори) і перевіряє їх. Роботу розподілено між агентами на основі великих мовних моделей:

- **аналітик** ділить лекцію на тематичні блоки, визначає стелю рівня таксономії Блума кожного блока й формує довідку (галузь, глосарій);
- **генератор** створює завдання для блока з поясненням типової помилки студента, яку моделює кожен дистрактор;
- **критик** перевіряє завдання у два етапи (етап 1 – фактологія, однозначність, мовна коректність; етап 2 – підказки за формою відповідей, правдоподібність дистракторів) і для відхиленої версії формує XAI-звіт ⟨E*, ρ, ι⟩: дефектні елементи, причину й вказівку щодо виправлення;
- генератор у режимі виправлення змінює **лише елементи з E\***, решту завдання код копіює без змін; цикл триває не більше п’яти ітерацій.

Якість готових завдань оцінює незалежний **арбітр** (інша модель, без тексту лекції, сліпий протокол) за чотирма критеріями: фактологічна коректність, однозначність, правдоподібність дистракторів, відсутність підказок.

## Структура репозиторію

| Шлях | Призначення |
|---|---|
| `backend/lecture_graph.py` | конвеєр агентів – граф станів LangGraph для конфігурацій M1–M4: вузли `check_size → analyst → allocate → generate → verify → summarize`, граф завдання `critic ⇄ refine` |
| `backend/generator.py` | агент-генератор (режим генерації) |
| `backend/critic.py` | агент-критик, режим виправлення (`local_regenerate`), виклики моделей |
| `backend/arbiter.py` | незалежний арбітр, незалежний розв’язувач, класифікатор рівня Блума, детерміновані перевірки підказок (`code_shortcut_checks`) |
| `backend/rules/rules.json`, `backend/rules/prompts/` | декларативні правила перевірки, шаблони XAI-звіту, ліміти та тексти промптів агентів |
| `backend/main.py` | вебсервіс FastAPI: REST API та WebSocket `/ws/logs` |
| `backend/experiment.py`, `backend/metrics.py`, `backend/stats.py` | запуск експерименту, метрики однорідності варіантів і статистичний аналіз |
| `frontend/` | вебклієнт React + Vite (введення лекції, хід генерації, результати з історією доопрацювання) |
| `dataset/` | маніфест експериментального набору (без текстів лекцій): ідентифікатор, дисципліна, назва, обсяг у символах і словах, SHA-256 кожної лекції |
| `results/` | журнали прогонів конфігурацій M1–M3 (стан кожного кроку конвеєра, оцінки арбітра, метрики; тексти блоків лекції вилучено) і зведена таблиця оцінок усіх 432 завдань M1–M4 `global_test_results.xlsx` |

## Встановлення

Потрібні Python 3.12 і Node.js 20+.

```bash
pip install -r backend/requirements.txt
cd frontend && npm install
```

Скопіюйте `.env.example` у `.env` і впишіть ключі API (DeepSeek – генератор і критик, Anthropic – аналітик і арбітр). Файл `.env` у репозиторій не додається.

## Запуск вебзастосунку

```bash
cd backend && python main.py          # http://localhost:8000
cd frontend && npm run dev            # http://localhost:5173
```

На Windows обидва процеси запускає `start_web.bat`.

## Відтворення експерименту

Тексти лекцій не публікуються, оскільки є авторськими матеріалами викладача. Склад набору зафіксовано маніфестом `dataset/manifest.json`: той, хто має оригінали лекцій, може покласти їх у `dataset/pdf/` і звірити з маніфестом за SHA-256, обсягом у символах і словах.

```bash
cd backend
python experiment.py status           # стан етапів для кожної лекції й конфігурації
python experiment.py run M4           # генерація + цикл критика, арбітр, метрики
python experiment.py index            # results/index.json для stats.py
python stats.py ../results/index.json
```

Кожен вузол графа зберігає результат у каталозі прогону (`analyst.json`, `alloc.json`, `gen.json`, `bNN_i.json`, `summary.json`), тому перерваний прогін продовжується з місця зупинки без повторних звернень до моделей.
